## 📌 Visão Geral

O projeto consistiu no desenvolvimento do **Observatório de Dados de Votorantim**, uma solução focada no **Setor de Serviços**. O objetivo foi coletar, tratar e estruturar dados socioeconômicos públicos e transformá-los em **dashboards interativos no Power BI**, fornecendo inteligência de mercado para apoiar gestores públicos, pequenos empresários e a comunidade local.

---

## 📁 O que foi Desenvolvido

- **Coleta e ETL de Dados:** Ingestão de dados da API do IBGE (SIDRA - Tabelas 6450, 9528 e 5938), cadastros da Receita Federal (MEI) e Ministério do Turismo (Cadastur).
- **Tratamento Automatizado via Python:** Desenvolvimento de rotinas em Python (`Pandas`, `Requests`) em ambiente Jupyter Notebook para consolidação, classificação por CNAE 2.0 e categorização setorial.
- **Modelagem Dimensional:** Construção de um modelo *Star Schema* diretamente no Power Query.
- **Dashboards Interativos:**
  - **Visão Geral Econômica:** Panorama comparativo entre Serviços, Indústria, Comércio e Agricultura.
  - **Análise Setorial Detalhada:** Drill-down por hierarquia de CNAE (Seção, Divisão, Grupo e Classe).
  - **Nichos Estratégicos:** Painéis focados em Comércio Varejista, Tecnologia da Informação (TI) e Turismo.
- **Validação e Apresentação:** O projeto foi apresentado e validado junto à Associação Comercial de Sorocaba (ACSO).
